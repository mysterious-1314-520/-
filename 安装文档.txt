祈福导航系统 V1.3 安装文档

欢迎使用祈福导航系统 V1.3 正式版。

一、安装环境

1. PHP >= 7.4。
2. MySQL 5.6+，推荐 MySQL 5.7 或 MariaDB 10.x。
3. Web 服务支持 Apache、Nginx、IIS，站点默认首页需包含 index.php。
4. PHP 扩展需开启 mysqli 或 pdo_mysql、mbstring、curl。
5. 目录权限：config.php、install/、images/bg/ 需要可写。
6. 本系统无需配置伪静态，正常绑定域名到程序根目录即可访问。

二、安装步骤

1. 将程序全部上传到网站根目录。
2. 访问绑定域名，系统会自动进入 /install/ 安装流程。
3. 按页面提示填写数据库地址、端口、数据库名、用户名和密码。
4. 点击创建数据表，看到安装完成后进入后台。
5. 默认后台地址：域名/admin/。
6. 默认管理员账号：admin，默认管理员密码：123456。
7. 首次登录后台后，请立即修改管理员密码。
8. 确认 install/ 目录下已生成 install.lock，避免重复安装。

四、功能特色

1. 前台导航首页：支持分类展示站点、搜索入口、快捷标签、公告、时钟显示。
2. 站点管理：支持添加、编辑、删除、启用/隐藏站点，支持分类、描述、图标、排序管理。
3. 描述跑马灯：支持长描述滚动展示、速度设置、7 种颜色和彩色混合效果。
4. 分类管理：可自定义导航分类名称、图标、排序和启用状态。
5. 友链申请：前台用户可提交友链申请，后台可审核通过或拒绝。
6. 邮件通知：支持配置 SMTP 邮箱，审核结果和测试邮件可通过后台发送。
7. 背景设置：内置默认背景 images/moren.jpg，支持自定义上传和必应每日壁纸。
8. 前台界面设置：支持卡片大小、网格列数、时间格式、显示开关和动画开关。
9. 背景音乐与延迟检测：支持配置背景音乐、音量和站点 Ping 延迟显示。
10. 后台简约 UI：支持侧边栏分组、右侧内容局部刷新、顶部固定和全宽内容布局。
11. 关于我们：展示官方开源信息、官网入口和服务器实时运行状态。
12. 服务器状态：支持 CPU、内存、硬盘、GPU、PHP、数据库、站点数量、点击数据等实时展示。
13. 访问统计：后台可查看今日浏览、总浏览、近 14 天趋势和站点访问情况。
14. 系统工具：支持操作日志、数据备份、数据恢复和管理员密码修改。

五、安装后建议

1. 首次登录后台后请立即修改默认管理员密码。
2. 根据站点定位修改网站名称、LOGO、公告、背景、搜索入口和前台显示设置。
3. 根据需要配置 SMTP 邮箱，便于友链审核和测试邮件通知。
4. 确认 install/install.lock 已生成，避免重复安装。
5. 正式上线前建议先执行一次数据备份。

六、常用文件位置

1. 网站图标：根目录/favicon.ico。
2. 默认背景：根目录/images/moren.jpg。
3. 数据库配置：根目录/config.php。
4. 安装锁文件：根目录/install/install.lock。
5. 安装 SQL：根目录/install/install.sql。
6. 后台样式：根目录/admin/saiadmin-skin.css。
