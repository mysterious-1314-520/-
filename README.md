# 祈福导航系统 V1.3

一个美观、响应式的自建导航网站系统，支持站点管理、分类管理、友链申请、背景设置、广告投放、Ping 延迟检测等功能。

---

## 功能特色

| 模块 | 说明 |
|------|------|
| 前台导航首页 | 分类展示站点、搜索引擎切换、快捷标签、公告、数字时钟 |
| 站点管理 | 添加/编辑/删除/启用/隐藏站点，支持分类、描述、图标、排序 |
| 描述跑马灯 | 长描述滚动展示，4 档速度，8 种颜色（含彩色渐变） |
| 分类管理 | 自定义导航分类名称、图标、排序和启用状态 |
| 友链申请 | 前台用户提交友链申请，后台审核通过或拒绝 |
| 邮件通知 | SMTP 邮箱配置，审核结果可邮件通知 |
| 背景设置 | 默认背景 / 自定义上传 / 必应每日壁纸 |
| 界面设置 | 卡片大小、网格列数、时间格式、显示开关、动画开关 |
| 背景音乐 | 自定义背景音乐链接和音量 |
| Ping 延迟 | 站点可访问性检测和延迟显示 |
| 广告投放 | 搜索下方 / PC 左右侧边广告位展示 |
| 服务器状态 | CPU、内存、硬盘、PHP、数据库实时展示 |
| 访问统计 | 今日/总浏览、14 天趋势、站点访问排行 |
| 系统工具 | 操作日志、数据备份/恢复、密码修改 |
| 响应式适配 | 全部设备（手机/平板/PC/宽屏）完美适配 |

## 安装环境

- PHP >= 7.4
- MySQL 5.6+ / MariaDB 10.x
- PHP 扩展：mysqli 或 pdo_mysql、mbstring、curl
- Web 服务：Apache / Nginx / IIS

---

## 安装步骤

1. 将程序全部上传到网站根目录
2. 访问绑定域名，系统自动进入 `/install/` 安装流程
3. 按页面提示填写数据库信息并创建数据表
4. 默认后台地址：`域名/admin/`
5. 默认管理员账号：`admin`，密码：`123456`
6. 首次登录后请立即修改管理员密码
